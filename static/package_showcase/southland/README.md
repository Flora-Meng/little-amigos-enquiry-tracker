# Southland showcase assets

The public guide is available at `/party-guide/southland/`.

Keep customer invitations and any image containing a child's name, phone number,
party date, or RSVP details out of this public folder. Add only approved showcase
photography here. Optimise each image to WebP or JPEG before committing it, target
roughly 1600 px on the longest edge, and keep each file below 500 KB where possible.

Theme cards are intentionally image-free until approved public theme photographs
are supplied. Their catalogue, labels, search, and category filters are already in
place so photographs can be added without changing the public URL.
